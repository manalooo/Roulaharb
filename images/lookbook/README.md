Two subfolders, one per collection year:
- images/lookbook/2022/   ← Roula wearing the 2022 collection
- images/lookbook/2023/   ← Roula wearing the 2023 collection

(Add more year folders later: 2024/, 2025/, etc.)

# What to drop in

What works best for a lookbook:
- Full-body shots in natural light
- Half-body / portrait crops showing detail of garment
- Detail shots — fabric in motion, embroidery close-up
- Editorial poses — looking away, not just camera-facing
- Outdoor / location shots if you have them (Beirut backdrop is gold)
- A mix of vertical (portrait) and horizontal (landscape) helps the layout breathe

# Naming

- look-1.jpg, look-2.jpg, look-3.jpg, ...
- Or any filename — I'll rename + compress when wiring them in

# How many

- 4-6 per collection is the sweet spot
- 1 hero shot + 3-5 supporting = 4-6 total
- If you have 10+ per year I can build an expandable gallery

# Optional metadata (tell me when you're done)

For each image, if you remember:
- Which piece is she wearing? (helps connect lookbook to the product grid via name)
- Where shot? (Beirut, studio, etc.)
- Any quote / caption from her about the shoot?

Otherwise I'll do it nameless / locationless — still beautiful.
